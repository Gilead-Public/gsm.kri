# Criterion type colours

\`r lifecycle::badge("experimental")\`

Fill colours of the Criteria charts, keyed by criterion type in stack
order.

## Usage

``` r
elig_CriterionColors(lSetup = elig_Setup())
```

## Arguments

- lSetup:

  \`list\` from \[elig_Setup()\].

## Value

Named \`character\` of hex colours.
