# Breakdown bar chart specification

Horizontal stacked participant counts with the total past the bar end.

## Usage

``` r
elig_BreakdownBarSpec(vOrder, strAxisLabel, vColors)
```

## Arguments

- vOrder:

  \`character\` Key order.

- strAxisLabel:

  \`character\` Category axis label.

- vColors:

  \`character\` Colours named by fill value, in stack order.

## Value

\`list\` chart specification for \`gsm.vizr::bars()\`.
