Criterion slices (criteria view A)

``` r
elig_CriteriaRows(dfElig)
```

## Arguments

- dfElig:

  \`data.frame\` from \[elig_ClassifyParticipants()\].

## Value

\`list\` from \[elig_BreakdownRows()\], keyed by criterion code and
filled by Inclusion / Exclusion.
