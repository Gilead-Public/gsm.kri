# Eligibility status colours

\`r lifecycle::badge("experimental")\`

Standard GISMO flag palette, keyed by status in chart stack order (first
is the base of the bar).

## Usage

``` r
elig_StatusColors(bPilot = TRUE)
```

## Arguments

- bPilot:

  \`logical\` Include Potentially Ineligible. Default: \`TRUE\`.

## Value

Named \`character\` of hex colours.
