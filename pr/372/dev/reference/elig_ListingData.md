# Ineligibility listing data

PD is \`"N/A"\` when the source is not delivered.

``` r
elig_ListingData(dfElig)
```

## Arguments

- dfElig:

  \`data.frame\` from \[elig_ClassifyParticipants()\].

## Value

\`data.frame\`.
