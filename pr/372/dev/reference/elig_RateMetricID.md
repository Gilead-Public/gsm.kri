# Rate metric of the eligibility results

The module passes qtl0001 only; older callers rename it (for example
\`"study_eligibility"\`), so the rate is whichever metric is not the
risk one.

## Usage

``` r
elig_RateMetricID(dfResults)
```

## Arguments

- dfResults:

  \`data.frame\` Reporting results.

## Value

\`character\` MetricID.
