# Shiny bindings for Widget_PortfolioOverview

Shiny bindings for Widget_PortfolioOverview

## Usage

``` r
Widget_PortfolioOverviewOutput(outputId, width = "100%", height = "600px")

renderWidget_PortfolioOverview(expr, env = parent.frame(), quoted = FALSE)
```

## Arguments

- outputId:

  output variable to read from

- width, height:

  Must be a valid CSS unit

- expr:

  An expression that generates a Widget_PortfolioOverview

- env:

  The environment in which to evaluate expr.

- quoted:

  Is expr a quoted expression?
