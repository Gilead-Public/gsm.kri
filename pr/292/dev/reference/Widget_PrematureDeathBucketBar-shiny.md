# Shiny bindings for Widget_PrematureDeathBucketBar

Shiny bindings for Widget_PrematureDeathBucketBar

## Usage

``` r
Widget_PrematureDeathBucketBarOutput(
  outputId,
  width = "100%",
  height = "400px"
)

renderWidget_PrematureDeathBucketBar(
  expr,
  env = parent.frame(),
  quoted = FALSE
)
```

## Arguments

- outputId, width, height, expr, env, quoted:

  htmlwidgets Shiny binding params.
