# IP Monitoring status vocabulary

\`r lifecycle::badge("experimental")\`

Status labels in stack order (bottom to top) with their colours. The
three not-dosed labels must equal the \`ipns_status\` values
gsm.mapping's IPNS mapping emits; the four dosed labels follow
\`drv_drg_completion\`.

## Usage

``` r
ipm_StatusColors()
```

## Value

Named \`character\` vector of hex colours.
