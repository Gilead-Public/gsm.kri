# Shiny bindings for Widget_PrematureDeathReasonBar

Shiny bindings for Widget_PrematureDeathReasonBar

## Usage

``` r
Widget_PrematureDeathReasonBarOutput(
  outputId,
  width = "100%",
  height = "400px"
)

renderWidget_PrematureDeathReasonBar(
  expr,
  env = parent.frame(),
  quoted = FALSE
)
```

## Arguments

- outputId, width, height, expr, env, quoted:

  htmlwidgets Shiny binding params.
